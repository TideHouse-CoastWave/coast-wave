# Coast Wave — One Page Event Website

## Run it
1. Open this folder in VS Code.
2. Open Terminal.
3. Run: `npm install`
4. Run: `npm run dev`
5. Open the local URL Vite shows.

## Edit event name
Open `src/main.js` and change:
`const EVENT_NAME = "COAST WAVE";`
